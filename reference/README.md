# Vendored FeatureScript reference

This directory is generated by `python3 scripts/fetch_reference.py` and is
safe to commit. The content is Onshape/third-party material, vendored so the
local MCP tools can answer FeatureScript questions without a network round trip.

## fsdoc/

- 20 official documentation pages from `https://cad.onshape.com/FsDoc/` (the
  FeatureScript function/type reference, the language guide, and the tutorial).
  © Onshape. Used for local reference; see the Onshape terms of service.

## std-library/

- 265 FeatureScript standard library source files, mirrored from
  `https://github.com/javawizard/onshape-std-library-mirror` (branch `without-versions`).
  The mirror auto-updates from Onshape and is MIT-licensed; `LICENSE.txt` is
  vendored alongside the sources.

## Updating

Re-run the fetch script to re-sync both trees. Then re-run the index builder,
which parses `library.html` into `index.json` and the guide pages into
`guide.json` (both record source sha256 for staleness checks):

```bash
python3 scripts/fetch_reference.py
python3 scripts/build_fsdoc_index.py
```
