## 1. 这次要验证什么

用户要求：**重启桥之后，在同一个文档里做一个 4U 的盒子，验证工具链正常**。所以本页同时
记两件事：

1. **桥重启后跑的是新代码**（有一个可判别的探针，见第 3 节）；
2. **工具链端到端正常**：夹具驱动 → 变量 → 草图 → 加料拉伸 → 内腔草图 → 切除拉伸 →
   STEP 导出，并且几何与解析公式**逐位相等**（第 5 节）。

## 3. 桥重启，以及「跑的是新代码」的判别

- 重启前：`ownedGeneration 80`、`activeClients 5`；重启后：`stoppedGeneration 80` /
  `startedGeneration 81`，`preservedClients 5`，`reconnectRequired false`。
- 判别探针（**只有新代码会这样拒绝**）：`browser_export_step(source_tab="网格底板", …)`，
  文档里存在 `网格底板 2×2`。
  - 实测返回：`ValueError: Part Studio tab '网格底板' must match exactly one visible tab name
    (exact match): matchCount=0, containingName=['网格底板 2×2'], tabs=[…]`；
  - 旧代码（子串 + `.first`）会命中 `网格底板 2×2` 并**继续导出**，不会拒绝。
  所以这条拒绝同时证明：部署的新代码在跑，且浏览器腿在重启后自动接回（探针顺带列出了
  6 个存活标签，含已删除项不再出现）。
- 同一轮还实测了新的改名路径：`Part Studio 2` → `4U 机箱盒子`（精确匹配 + 按 `data-id`
  右键），返回 `renamed: true` 且标签条复读一致。

## 4. runner 的传输超时与「落地无收据」行

夹具首次 `run_project` 在客户端侧以 `MCP error -32001: downstream_timeout` 结束，服务端继续
执行；checkpoint `updatedAt` 静止两分多钟后只记到 `04-outer-sketch`（`completed` 5 项），
**但真实树里已经有第 5 步的行**（`TE Thin Extrude 1` + `Part 1`，表头 `特征 (10)`）。

处理（只用受支持的工具）：

1. `browser_delete_feature("TE Thin Extrude 1")` → 判据「行离开列表」，树回到 5 行，与
   checkpoint 的 5 项对齐；
2. `run_project(resume=true)` → **8/8 完成**，`ok: true`，每步 `inserted: true`、
   `applyState: "verified"`，`06-inner-sketch` 的表达式解析为 `3 mm / 476.6 mm / 294 mm`，
   `07-inner-cut` 结束后 `零件数 (1)`。

这条补进了 `onshape_docs/experience/browser-modeling.md` 第 20 节的补充段：**checkpoint
静止不等于恢复安全**，恢复前要把真实树与 `completed` 对齐。

## 5. 验收：STEP 与解析公式逐位相等

解析（开口向上的长方形盒，`W=482.6, D=300, H=177.8, t=3`）：

```text
体积 = W·D·H − (W−2t)(D−2t)(H−t)              = 1248838.08 mm³
面积 = 底 + 外墙 + 顶环 + 内墙 + 内底          = 837254.32 mm²
面数 = 外底1 + 外墙4 + 顶环1 + 内墙4 + 内底1   = 11
水平面 z = 0 / 3 / 177.8
```

STEP 实测（`onshape_docs/scripts/verify_step_brep.py`）：

| 量 | STEP 实测 | 解析值 |
|---|---|---|
| volumeMm3 | `1248838.08` | `1248838.08` |
| surfaceAreaMm2 | `837254.32` | `837254.32` |
| faceCount | `11` | `11` |
| horizontalPlaneZs | `[0.0, 3.0, 177.8]` | `[0, 3, 177.8]` |

逐位相等。也就是说这次构建不仅「跑通了」，而且**尺寸驱动的表达式链路**（`#box_t`、
`#box_w - 2 * #box_t`、`#box_h`）确实进了几何，而不是只进了对话框。

## 6. 边界（本页不声明的东西）

- 只验收**这一个**尺寸组合；不声明任意尺寸、任意壁厚都能得到解析值（公式本身与本构型
  一致，但薄特征的取整/求解容差未做扫掠）。
- `4U = 177.8 mm` 取自 `1U = 44.45 mm`（19 吋机架惯例）；`19 吋 = 482.6 mm` 是外形宽度，
  未建模导轨间隙或面板孔。
- 盒子是**开口向上的槽体**，不是六面封闭的壳体；开口方向由「切除拉伸通顶」实现。
- 本页的桥重启是**共享桥**的一次生命周期操作：5 个客户端被保留，未修改桥代码。
